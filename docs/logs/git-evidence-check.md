# Git 증빙 재검토

이 파일은 첨부된 **소스 ZIP**에서 확인 가능한 사실만 기록합니다. `.git` 저장소가 포함되지 않아 과거 Git 기록을 새로 만들거나 확정할 수 없습니다.

- `git-history.txt`: 해당 시점 **15개 커밋**이 기록되어 있지만 문서·스크린샷 관련 커밋이 다수입니다. **의미 있는 기능별 커밋 10개**를 충족했다고 단정할 수 없습니다.
- `git-branches.txt`: 수집 시점에는 `main`만 표시됩니다. 병합 결과가 fast-forward였다면 별도 merge 커밋은 없을 수 있습니다. GitHub 원격 브랜치도 삭제되었을 수 있습니다.
- `git-reflog.txt`: 새 컴퓨터의 clone 한 줄만 보여 주므로 이전 컴퓨터의 브랜치 전환을 증명하지 않습니다.
- `clone-pull-verification.txt`: 별도 임시 폴더에서 clone하고 pull이 정상 동작했음을 보여 주지만, **다른 복제본에서 수정·push 후 원본에서 pull**한 과거 실습을 전부 증명하지는 못합니다.
- `git-remote.txt`: 실제 원격 저장소 설정 주소를 기록합니다.

현재 컴퓨터에서 `py tools/collect_git_evidence.py`를 실행하면 최신 로그와 상태 정보를 갱신할 수 있습니다. 실제 기능 단위 커밋이 부족하다면 앞으로의 **실제 코드 개선**을 수행할 때 기능별로 커밋해야 합니다. 커밋을 조작하거나 없는 병합 이력을 꾸미지 마세요.
